# Library Management System

**Cairo University**  
Faculty of Computers and Artificial Intelligence  
Database Systems -1 Course Project  

## 📋 Project Overview
A complete library management solution with:
- User authentication (Admin/Student roles)
- Book inventory management
- Advanced search functionality
- Database-backed operations

## 🛠️ Technical Implementation
- **Backend**: Python with MS SQL Server
- **Database**: Fully normalized schema (5+ entities)
- **Features**:
  - CRUD operations for books/users
  - Conditional searches (ISBN, author, year)
  - Transaction management
  - Basic reporting

## 🔗 Key Components
1. `ERD/` - Conceptual and physical database diagrams
2. `SQL/` - Database creation scripts with sample data
3. `src/` - C# application source code
4. `docs/` - Project documentation

## 🚀 Getting Started
1. Clone repository
2. Execute `SQL/library_db_init.sql`
3. Open solution in Visual Studio
4. Run `LibraryManagement.sln`
